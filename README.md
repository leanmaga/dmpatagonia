<h1 align="center">PatagoniaScript & D'Marketing Creativo</h1>
<h3 align="center">Desarrollo Web + Diseño & Marketing 🚀</h3>

---

Landing page de la alianza entre **PatagoniaScript** (desarrollo web) y **D'Marketing Creativo** (diseño e identidad visual + gestión de redes), pensada para ofrecer soluciones digitales completas: sitios web profesionales + identidad visual + marketing, todo en un mismo paquete.

> *"Desarrollo Web + Marketing Digital: La fórmula completa para el éxito online"*

---

### ✨ Funcionalidades

- 🤝 Presentación de la alianza entre ambos estudios
- 📦 Sección de paquetes combinados (web + diseño + marketing)
- 🎯 Bloque de propuesta de valor ("Todo Incluido", "2 Equipos", años de experiencia combinada)
- 💬 Sección "Nuestra Fusión" con la historia de ambas marcas
- 🔗 Enlaces a redes sociales de ambos estudios (X, LinkedIn, Instagram, Facebook)
- 🧭 Navegación lateral fija por secciones
- 📱 Carrusel de contenido con Swiper
- 📬 Formulario de contacto (EmailJS + Formspree)

### 🛠️ Cómo correrlo localmente

```bash
# Clonar el repo
git clone https://github.com/tu-usuario/patagoniascript-dmarketing.git
cd patagoniascript-dmarketing

# Instalar dependencias
npm install

# Configurar variables de entorno (conexión a MongoDB, claves de EmailJS/Formspree)
cp .env.example .env.local

# Levantar en modo desarrollo
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en tu navegador.
